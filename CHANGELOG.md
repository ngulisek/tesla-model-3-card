# Changelog

## 1.1.0

- Automatic Tessie vehicle discovery, with separate selection for multiple vehicles.
- Battery, range, charging, climate, location, and security readings.
- Recolorable Model 3 illustration, paint-sensor support, and custom images.
- Dark and light appearances with responsive layouts.
- Native and custom nested Home Assistant cards.
- Conditional visibility for built-in sections and individual nested cards.
- Visual visibility presets and YAML state, numeric, AND, OR, and NOT rules.
- Self-contained sample-data preview and installation examples.

Validation: 19 unit tests and desktop/mobile browser checks. Live installation
against a user's Home Assistant instance has not been verified.
